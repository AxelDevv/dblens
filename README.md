# DBLens — SQLite Viewer & Editor

**Free online SQLite viewer and editor.** Open `.db` and `.sqlite` files directly in your browser — no upload, no server, no registration required.

🔗 **Live site: [dblenss.vercel.app](https://dblenss.vercel.app)**

---

## Features

- **View tables** — browse data with sorting, filtering and pagination
- **Search across all tables** — find any value in the entire database at once
- **Edit data** — add, edit and delete rows directly in the browser
- **SQL editor** — write and run custom SQL queries with syntax highlighting
- **Schema viewer** — see column types, primary keys, indexes and DDL
- **Export data** — CSV, JSON, TSV, SQL, Markdown for current table or all tables at once
- **Light & Dark theme** — switch with one click
- **100% local** — your data never leaves your device
- **Mobile friendly** — works on iPhone and Android

## Supported formats

`.db` · `.sqlite` · `.sqlite3` · `.db3`

## How to use

1. Open [dblenss.vercel.app](https://dblenss.vercel.app)
2. Drop your SQLite file or tap to browse
3. Browse tables, run queries, export data

## Tech stack

- Vanilla HTML, CSS, JavaScript
- [sql.js](https://github.com/sql-js/sql.js) — SQLite compiled to WebAssembly
- Deployed on [Vercel](https://vercel.com)
